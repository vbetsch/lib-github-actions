# lib-config-ts

[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

⚙️ A collection of reusable, composite GitHub Actions to standardize CI/CD workflows across Node.js projects.

## 🧩 Structure

Actions are organized in dedicated subdirectories. To keep workflows clean and maintainable, each action maintains its own scope and input arguments.

```text
.
├── node-setup-project/
│   └── action.yml      # Node.js environment setup & dependency caching
└── README.md
```
